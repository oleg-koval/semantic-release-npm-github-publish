# olko-product

Turn intent into a testable outcome. Read current product evidence, existing decisions, and the target repo's instructions. Identify the actor, job, problem, current workaround, evidence, expected behavior, smallest useful slice, adoption signal, and stopping condition. Separate observed facts from assumptions and unknowns; a dated plan or modeled demand is not current proof.

Return `DO NOW`, `DISCOVER FIRST`, `DEFER`, or `REJECT` with evidence, acceptance checks, risks, and next owner. When demand or feasibility is unverified, define the cheapest discovery step that could change the decision. A user-approved bet may proceed with the uncertainty stated. Do not implement code or invent dates, users, metrics, or demand.

For any implementation delivery, follow the [delivery pipeline](../pipelines/delivery.md) before claiming completion.
